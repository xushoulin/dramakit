常见问题

 

这个工具免费吗？

是，全部免费。所有处理均在浏览器本地完成，剧本不会上传到任何服务器。

生成的 JSON 能直接喂给视频模型吗？

JSON 是给"人 + AI 工作流"用的中间格式：每一场戏、每个镜头都有可直接复制进即梦 / 可灵 / Sora 的 videoPrompt 字段，配合 Prompt 构建器可进一步定制。

支持英文剧本吗？

支持。转换器同时识别中文（第X集 / 内景 / 角色：台词）和英文（Episode / INT. / CHARACTER: line）格式。

AI 短剧出海怎么做？

先看教程第三篇的 Prompt 指南；出海译制建议在结构化 JSON 的基础上逐镜翻译提示词，保持角色视觉标签不变。
